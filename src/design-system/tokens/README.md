# Tokens do Design System

Área reservada para os tokens oficiais do IngCore, a serem documentados posteriormente.
Nenhum valor foi inventado ou importado nesta fase. Não importar os tokens do portal aqui.
Usar o prefixo `--ingcore-` e aplicar os futuros tokens apenas no escopo dos exemplos do DS.
O portal usa exclusivamente `--portal-*`, definidos em `src/portal/styles/tokens.scss`.
